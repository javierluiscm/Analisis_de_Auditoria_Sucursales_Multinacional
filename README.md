# 📊 Auditoría de Sucursales Multinacional

Este proyecto se desarrolla en el marco de la formación **“Estadística Esencial para Análisis de Datos con Python”** de la escuela **GROWUP DATA ANALYTICS**.  
El objetivo es aplicar técnicas estadísticas y de ciencia de datos para auditar y evaluar el desempeño de sucursales de una organización multinacional.

---

## 🎯 Objetivo del Proyecto
Analizar un conjunto de **10,000 registros de auditorías** con el fin de:
- Explorar y describir los datos (EDA).  
- Identificar valores atípicos y correlaciones.  
- Realizar pruebas de hipótesis sobre cumplimiento normativo.  
- Ajustar distribuciones estadísticas y simular escenarios.

---

## 📂 Variables del Dataset
- `branch_id`: ID de la sucursal  
- `country`: País de la sucursal  
- `auditor_id`: ID del auditor  
- `num_findings`: Número de hallazgos  
- `severity_score`: Gravedad de hallazgos (1–10)  
- `audit_score`: Puntuación total de la auditoría (1–100)  
- `compliance`: Cumplimiento normativo (0 = No, 1 = Sí)  
- `audit_duration_days`: Duración de la auditoría en días  

---

## 🧠 Metodología
1. **EDA**: Estadística descriptiva, pruebas de normalidad y visualización.  
2. **Outliers**: Detección y tratamiento de valores atípicos.  
3. **Inferencia**: Prueba t de Student para comparar sucursales cumplidoras vs. no cumplidoras.  
4. **Distribuciones**: Ajuste paramétrico y simulación de nuevos datos.  

---

## 🚀 Conocimientos Aplicados
- Python para análisis estadístico (Pandas, NumPy, SciPy, Matplotlib, Seaborn).  
- Técnicas de inferencia y pruebas de hipótesis.  
- Modelado de distribuciones y simulación de datos.  
- Buenas prácticas en ciencia de datos y auditoría financiera.
